APERICOPO 2.0 — COPPO AI VERO

1. Crea una chiave API OpenAI dal tuo account API.
2. NON inserire mai la chiave dentro index.html.
3. Sul servizio di hosting imposta la variabile ambiente OPENAI_API_KEY.
4. Opzionale: OPENAI_MODEL=gpt-5.4
5. Avvia con: npm install && npm start

Se il backend /api/coppo non è disponibile, il sito usa automaticamente il motore locale già incluso.
